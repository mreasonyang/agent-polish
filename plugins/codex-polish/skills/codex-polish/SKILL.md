# 用 Gemini 改写回复

用户主动要求润色时，用 `--trigger explicit` 按[回复润色流程](WORKFLOW.md)直接交给 Gemini 用 Turbo 改写。要改之前的答复，就取用户指的那一条。用户只想了解功能时直接回答，想改项目设置或全局润色提示词时使用设置技能。
